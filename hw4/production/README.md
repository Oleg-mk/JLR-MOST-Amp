# Bitline, 4-шарова плата: файли для виробництва

Згенеровано з плати `jlr_most_amp.kicad_pcb` у теці вище (у репозиторії JLR-MOST-Amp це `hw4/`) скриптом
`hw/gen/fab.py`. Основа — коміт 3da3689. DRC: 0 помилок, 0 нерозведених,
0 розбіжностей зі схемою.

## Файли

| Файл | Для чого |
|---|---|
| `Bitline-4L-gerbers.zip` | завантажити на сайт виробника: Gerber усіх шарів + свердління |
| `gerbers/` | те саме розпаковане: F/In1/In2/B Cu, Mask, Paste, Silkscreen, Edge.Cuts, `PTH.drl`, `NPTH.drl`, `job.gbrjob` |
| `Bitline-4L-BOM.csv` | перелік деталей у колонках JLCPCB: Comment, Designator, Footprint, Quantity, LCSC Part # |
| `Bitline-4L-CPL.csv` | координати й повороти для монтажу (Designator, Mid X, Mid Y, Layer, Rotation) |
| `Bitline-4L-assembly-top.pdf`, `-bottom.pdf` | складальні креслення: контури, піни й усі позначення; низ у дзеркалі, як дивитися на нижній бік |
| `Bitline-4L-PTH-drl_map.pdf`, `-NPTH-drl_map.pdf` | карти отворів |
| `Bitline-schematic.pdf` | схема |

## Замовлення плати (поля форми JLCPCB)

- Шари: 4. Розмір: 120.1 × 58.6 мм. Одна плата, без панелі.
- Порядок шарів:

  | Шар | Файл | Що на ньому |
  |---|---|---|
  | L1 | F.Cu (`.gtl`) | живлення, переходи сигналів, GND-заливка |
  | L2 | In1.Cu (`.g1`) | суцільна GND |
  | L3 | In2.Cu (`.g2`) | суцільна GND |
  | L4 | B.Cu (`.gbl`) | сигнали й більшість деталей |
- Товщина 1.6 мм. Стек JLC7628: препрег 0.2104 мм, ядро 1.065 мм. Зовнішня мідь 1 oz, внутрішня 0.5 oz.
- Щоб пари HDMI I2S мали розрахований імпеданс, у формі вибрати контроль імпедансу зі стеком JLC7628.
- Найтонша доріжка 0.2 мм, найменший зазор 0.15 мм (правила плати 0.15/0.15).
- Переходи 0.6/0.3 мм, 244 шт. Найменший отвір 0.3 мм.
- Пази з металізацією: J10 (0.5×1.1 і 0.5×1.7 мм) і J7 (0.9×2.7 мм). Отвори без металізації: 3 × 2.7 мм для
  кріплення (H1, H3, H4) і фіксатори J2, J7, U5. H2 металізований: отвір 2.7 мм, кільце 5.2 мм на GND, це зв'язок маси
  з корпусом.
- Маска й шовкографія з обох боків, колір на смак.
- Покриття: ENIG. Краще за HASL для U8 (WQFN 3×4 мм), U7/U9 (WSON 2×2 мм) і корпусів TSSOP з кроком 0.65 мм.
- Номер замовлення JLC друкує на шовкографії, місця під нього на платі немає. Можна вибрати «Remove order number»
  або погодитися на їхнє місце.

## Монтаж

Деталі, сторони й позначення ті самі, що й на 2-шаровій платі.

- За BOM 146 деталей, 61 рядок.
- SMD: 124 знизу (B) і 10 зверху (F): C15, C16, C17, C37, C50, C65, C69, C70, C71, SW2. Варіанти:
  - двобічний монтаж у JLC (Standard PCBA);
  - або нижній бік на заводі, а 10 верхніх деталей вручну.
- Вивідні деталі, 12 шт.: зверху D20, J1, J2, J4, J5, J6, J7, J10, SW1, U5; знизу J8, J9 (штирі до лампової
  плати).
- J3 (штирі 1x4 для запису й журналу без USB) завод не ставить: у BOM і CPL його немає, на кресленні він перекреслений.
- Колонка «LCSC Part #» порожня. Її заповнюють при підборі деталей у JLC, або деталі постачають самі.
- Перевірити, чи є в наявності:
  - U1 OS8104AAQ (MOST-контролер, знятий з виробництва);
  - J2 TE 1-1394640-1;
  - U5 Everlight PLT133/T10W;
  - J10 USB-C з боковою вставкою (AliExpress 1005006026498474);
  - U2 ESP32-WROVER-IE-N16R8;
  - J7 Kycon HDMI;
  - J4–J6 BKL 0101153;
  - J1 Molex 43045-0421;
  - SW1 DP-04 (клавішний DIP).
- Координати в CPL абсолютні, від того самого нуля, що й Gerber. Повороти перевірити в попередньому перегляді JLC,
  особливо на нижньому боці та в полярних деталях: мікросхеми, LED D20, електроліти C50/C65, діоди.
